# Lucas FM 0.2

Sound selection now follows SLOOP's familiar part/preset arrangement, with a separate Lucas interface: colored sound cards on Home, a larger selected sound, an engine label and control hints on Sound, and explicit effect activity.

| Control | Home | Sound | Effects |
|---|---|---|---|
| ALGORITHM | Select part | Select part | Select part |
| PRESETS | Browse all sounds | Browse sounds in this engine | Modulation type / Grain pitch mode |
| SELECT | Tempo | Change engine | Choose effect |
| EDIT | Open Sound | Stay on Sound | Toggle selected effect on/off |
| HOME | Home | Home | Home |
| FX | Open effects | Open effects | Flip extra EQ / Grain page |

SCL opens key/tempo, ARP opens chord/piano playing, SEQ opens recording, LFO opens loops and GLO opens the mixer. Four-knob labels always describe the controls below the screen. PRESETS also works on Play/Mix. Drums browse kits instead of synth engines.

## Effects fixed and verified

EQ previously defaulted to bypass, with the bypass control hidden on a second page. Editing EQ now activates it, and ACTIVE/BYPASSED is visible. EDIT toggles an effect and remembers its previous amount within the running session. Grain now uses a true dry/wet crossfade with makeup gain for its windowed grains, so MIX produces an obvious change instead of a quiet additive layer. Parameter edits retry effects after CPU protection pauses them.

The audio path remains shared: EQ/Drive/Modulation/Grain process the master; Delay/Reverb use track sends. The limiter remains active. CPU protection and the four-import/eight-pitched-voice limits remain. Use the browser's **240 MHz** setting; full workloads at 100 MHz still overload.

## Ready to play

`dist/lucas-fm-0.2.fwsc` is the **play-ready emulator package**: ten public loops are resident on a fresh boot, alongside the retained factory sounds and drum kits. New songs start with an editable 808 beat; press PLAY. Existing autosaves keep their own patterns.

On the development Mac, `private/lucas-fm-0.2-personal.fwsc` contains your private collection and selected USR1 drum kit. It stays out of GitHub. The native launcher uses this package when available. Load that same file with the browser's Open .fwsc button to get the personal sounds without a separate import.

The update-only package is `dist/lucas-fm-0.2-update.fwsc`. The retained physical update loader preserves sample slots and does not install the extra preloaded data: use the companion editor to transfer a collection on physical hardware. This was not changed to erase users' samples. **No physical device has been flashed or tested.**

## Validation

Dedicated host tests exercise Home preset changes, Sound's engine and preset controls, part changes, EQ activation, effect bypass/restore, actual low-cut response, grain tail energy, project roundtrips and all display bounds. Seven Python pack tests cover corruption, capacity, independent pitch/tempo preparation and the preloaded package's exact bytes. Browser pack tests retain the existing editor format.

`tools/lucas_v02_check.py` boots the compiled play-ready package without a restored flash image or sample overlay. It checks all ten library entries, captures loop and drum-machine audio, then captures EQ, Drive, Modulation, Grain, Delay and Reverb, with EQ/Grain bypass cases. Large scripted encoder turns are given time to finish their physical quadrature edges before bypass is pressed.
