# Lucas FM 0.3 — controls first

A redesigned firmware interface for the physical FM-1, with the existing audio engines, public starter collection and personal sample support. This project is separate from TeleNeuMu. No physical device was flashed.

SELECT now selects parts/items; ALGORITHM selects synthesis engines, FX processors, LFO waveforms or arp patterns; PRESETS browses sounds or relevant settings. The four Home knobs directly mix the four colored parts. Loops is a visible Home destination. SCL opens scale/chord playing; ENV, LFO and ARP now open the functions printed on those buttons. HOME is the universal return. Advanced SLOOP editors remain available with their original mappings.

Home has compact sound cards and level rails. Sound has a curved three-position browser and a clear engine identity. Scale/Play retains the numbered chord wheel and adds a recognizable piano guide. Envelope responds to the real ADSR settings. Mix shows four vertical faders; Sequence shows four lanes and playheads. Every page uses the same aligned four-knob footer, part colors, transport indicators and unsaved-change dot.

FX PRESETS loads Flat/Warm/Air EQ, Soft/Crunch/Crush drive, Tight/Dotted/Echo delay or Room/Hall/Cloud reverb. Modulation selects Chorus/Vibrato/Tremolo/Phaser; Grain selects Octaves/In Key/Free pitch. Knob changes mark a named starting point as Custom. EDIT bypasses/restores; the amount and active state remain visible. These controls change the real DSP, not a browser simulation.

The old SLOOP HOME-on-HOME visualizer was unreachable because Lucas HOME always returns to performance. It is now excluded only from Lucas builds, freeing flash and RAM. Its upstream implementation remains in the source. Audio engines, sample data, the flash map, storage format and physical update loader remain unchanged.

The public emulator package includes ten imports and the starter drum machine. The personal package remains in ignored `private/` storage and includes the user's local kit. Physical firmware updates preserve sample slots; collection transfer still uses the editor. Four imports and eight pitched voices remain the practical limits, with visible CPU protection for heavy engines.

## Quick controls

- HOME → SELECT part → PRESETS sound; ALGORITHM changes engine.
- EDIT → Sound; EDIT again → engine controls; repeat for the next bank/back.
- SCL → Key / Scale / BPM / Keys; EDIT toggles Hold.
- HOME → SELECT Loops → EDIT; SELECT clip → EDIT to start/stop.
- ENV / LFO / ARP / FX / GLO / SEQ open their named functions.
